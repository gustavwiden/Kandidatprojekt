# Parameters Files Overview

This folder contains the `.json` and `.csv` files with the parameter sets used to run the scripts.

All acceptable parameter sets found during PL-analysis have been gathered in single file for each pDC density. These files are used to plot the simulation uncertainty bands.
* [`acceptable_params_PL_1.csv`](acceptable_params_PL_1.csv) (1 pDC/mm² in skin)
* [`acceptable_params_PL_80.csv`](acceptable_params_PL_80.csv) (80 pDCs/mm² in skin)
* [`acceptable_params_PL_400.csv`](acceptable_params_PL_400.csv) (400 pDCs/mm² in skin)

The best parameter set found during parameter estimation have been gathered in a single file for each pDC density. This file is used to plot the simulation.
* [`final_params.json`](final_params.json)
